# Remastered package contract and allocation safety

Baseline6be0406983905c6be4b758c40ac0af6aa9abece9, 2026-10-27. This fixes a regression introduced by #390 and a separately reproduced unsafe sibling reader. No original game assets or reporter-specific cause are asserted.

Regression: a generated, structurally valid MVS package contains a99-byte base and35-byte UK table, each with an8-byte declared decoded-size hint. Python before390 returns the complete tables; the unchanged C++ ReadAssetExtras also accepts them (its documented contract is inflatedLen>=real). Python after390 rejects with decoded-length mismatch. The earlier16-case package gate covered exact-size assets and missed this remastered contract. This change restores >=hint when with_remastered is requested. Ordinary C++ ReadAsset already required exact decoded size before390; that separate contract and its existing16-case gate remain unchanged. Python ordinary assets retain that exact-size check.

Sibling failures: ReadAssetExtras still allocated from unchecked signed lengths and published the base before an extra failed. A16-byte negative base header throws; negative/truncated extra metadata leaves partial caller output; codec-3 was accepted. Tests reproduced these before the fix. Stored sizes/header counts/offsets now must fit the actual stream before allocation or reads. Decoding uses the existing actual-output allocator and preserves the remastered >=hint rule. Output base/map are staged and swapped only after the entire package succeeds. Final alignment padding may be absent as before; actual payload bytes may not. Physical header bounds replace the guessed64-entry limit.

Gate: test_hd_remastered_safety.py runs13cases through the real C++ reader and Python reader, with raw/empty/padded/expanded controls, signs/codecs/truncation and failure-output preservation. It also invokes actual C++ ReadAssetLanguages and actual Python subtitle extraction from a generated HED/PKG: both complete MVS tables are retained and two us/uk files contain the exact expected cue text. Existing package16, SCD14/full native producer, worker lifecycle and media transaction tests remain green. Complete Windows launcher syntax is checked for x86/x64 with the existing toolchain. This does not certify proprietary corpus coverage, original Steam Machine/Proton behavior, or a new published artifact.
