# Guía de contribución

Leer `SKILL.md` y el módulo pertinente antes de modificar el método. OptiPort se presenta y aplica exclusivamente como optimización profesional de software general. Esta regla rige ejemplos, títulos, informes y explicaciones; evitar referencias a sectores ajenos al producto analizado y mantener el lenguaje centrado en sus flujos, resultados y evidencia.

Conservar los mecanismos verificados de memoria, caché, carga asíncrona, ciclo de vida, transacciones y medición. Las lecciones requieren evidencia y límites; no convertir el caso de una aplicación en una garantía para otra.

Para afirmar una mejora de rendimiento, registrar una comparación antes/después con carga, calidad y entorno equivalentes, resultados correctos y mediciones reproducibles. Separar implementado, verificado, publicado y pendiente. Una revisión documental no demuestra aceleración de ninguna aplicación.

Mantener enlaces locales válidos y referencias técnicas trazables. No reescribir el historial ni publicar datos privados. Aplicar únicamente los controles pertinentes al cambio; esta guía no concede autorización de publicación o integración.
