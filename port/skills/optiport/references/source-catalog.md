# Fuentes opcionales por mecanismo

Consultar el [catálogo de ingeniería y diseño](domain-sources.md) para geometría, dependencias, recomputación y edición. Las [lecciones verificadas](verified-lessons.md) conservan referencias de casos concretos de memoria, recursos, streaming, procesos y transacciones.

Elegir una fuente sólo cuando pueda resolver una incertidumbre del proyecto actual. Registrar archivo y commit, alcance leído, licencia y límites; no tratar popularidad ni una interfaz como validación de una implementación completa. No se ejecutó código de esas fuentes en esta revisión documental.

Las referencias históricas siguen disponibles en Git. Su evidencia corresponde al contrato original; no demuestra rendimiento, compatibilidad ni seguridad de otra aplicación. Antes de reutilizar código, revisar sus términos y probar la adaptación con las entradas y plataforma actuales.
